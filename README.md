# 房租计算器 · RCPR Evaluator

面向新城市租客的中文租房计算器与房源对比工具。它把租房判断拆成空间硬件、地理通勤和财务成本三类可解释的评分，支持比较三个房源；所有输入只保留在当前浏览器页面。

## 产品目标

- 识别不值得签的高风险房源：现金流压力过高、租金贷、污水粉碎机马桶、燃气安全隐患。
- 清楚展示空间、通勤、财务之间的取舍。
- 辅助看房决策，不替代实地验房、产权核验或合同审查。

## 核心功能

- 自动计算房租收入比、综合月成本和综合住房负担率。
- “暂不明确”从所在维度剔除，不会被误当作低分。
- 高风险触发红色警示并限制总分。
- 支持房源 A、B、C 切换比较。

## 评分框架

| 维度 | 权重 | 包含范围 |
| --- | ---: | --- |
| 空间硬件 | 40% | 独立性、采光、户型、做饭、隔音、排污、热水、燃气安全 |
| 地理通勤 | 30% | 门到门时间、换乘、门禁、配套、垃圾点卫生、外部噪音 |
| 财务成本 | 30% | 月租、押付、签约主体、水电性质 |

每个已知子项按 1.0–4.0 分评分。维度分取该维度内已知子项的平均值；总分按权重加权，并为完全未知的维度重新归一化：

`总分 = Σ(维度权重 × 维度平均分) ÷ Σ(已知维度权重)`

信息不足时，结果应被视为“待核实”，而不是确定推荐。

## 财务计算器

`房租收入比 = 月租金 ÷ 税后月收入`

`综合月成本 = 房租 + 电费 + 水费 + 热水/燃气 + 网络固定费 + 月通勤交通`

`综合住房负担率 = 综合月成本 ÷ 税后月收入`

其中电费 = 用电度数 × 电价，水费 = 用水吨数 × 水价。热水/燃气单列，避免把实际支出误计为“水电”。民水民电、商水商电及高能耗的差异会反映为真实月成本。

### 城市建议线

| 城市等级 | 默认建议线 |
| --- | ---: |
| 超一线 | 30% |
| 一线 | 28% |
| 新一线 / 二线 | 26% |
| 三线 | 24% |
| 四线及以下 | 22% |

30% 是国际住房负担讨论中常用的可支配收入警戒线。城市档位是透明的产品默认值，不是国家统计局或国际组织发布的官方工资标准；实际使用应优先考虑个人税后收入、稳定支出与当地公开租金数据。[联合国住房负担参考](https://digitallibrary.un.org/record/4021361/files/A_78_192-ZH.pdf) · [重点城市租金收入比口径](https://www.cih-index.com/news/2025-07-04/53072947.html)

财务子项按建议线 `T` 评分：`≤0.8T` 为 4.0，`≤T` 为 3.5，`≤1.2T` 为 2.5，`≤40%` 为 1.5；超过 40% 锁定 1.2 分。

## 硬风险规则

| 风险 | 总分上限 |
| --- | ---: |
| 综合住房负担率超过 40% | 1.2 |
| 年付或租金贷 | 1.5 |
| 老旧燃气、通风差或私接明火 | 1.5 |
| 污水粉碎机马桶 | 1.8 |

“做饭能力”与“燃气消防安全”分开评分：独立厨房或安全电磁烹饪属于便利性；明火本身不加分，通风、报警设备与燃气状态才决定安全性。

## 使用方式

1. 在仓库主页点击绿色 **Code**。
2. 选择 **Download ZIP**，下载后解压。
3. 双击解压目录里的 `index.html`，浏览器会直接打开计算器。

这是纯静态网页，不需要安装依赖、注册账户或启动服务器。

## 隐私

本项目不主动发起网络请求，也不使用浏览器存储持久化保存用户输入的数据。

## 技术

使用原生 HTML、CSS 和 JavaScript 开发，无需构建步骤、后端服务或第三方依赖。
